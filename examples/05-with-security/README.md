# Example 05: セキュリティと承認

セキュリティフックと承認システムを統合したサンプルです。

## 学べること

1. **多層防御**
   - ツール設定レベルの制限
   - セキュリティフックによるパターンマッチング
   - 承認フックによる動的ゲート

2. **ApprovalSystem**
   - `ask_user` アクションの処理
   - タイムアウト管理
   - 承認キャッシュ

3. **統合されたセキュリティ**
   - パスバリデーション
   - コマンド検証
   - ユーザー確認

## 実行方法

```bash
cd examples/05-with-security
python3 app_standalone.py
```

## 学習ポイント

このサンプルでは、Example 04のセキュリティフックに加えて、承認システムを追加します。
危険な操作は自動的にブロックされ、警告レベルの操作はユーザーに確認を求めます。
